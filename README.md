# shellneko
A 16x16 px Neko recreation using shell, awk and socat.

# Info
shellneko is made up of the three shell scripts presented in this repo:

### build_cpu.sh
the underlying minsky machine comprising the needed registers and state machinery.

### ppu.sh
the shell script containing the pixel processing unit, sprites and related functions.

### run.sh
the initialisation and setup script.

### Note: shellneko requires a working X11 or xwayland environment with socat installed
